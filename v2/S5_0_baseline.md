# S5-0 — horizon 10 s 기준선

## 결론

**확인:** `horizon_s=10.0` 전수 배치(1,620 인스턴스 × 3 planner seed, wm_planner 4,860행)가 완료됐다. 성공률은 S2의 87.84%에서 **93.66%**로 +5.82%p 올랐고(전이 329승/46패, 부호검정 `p=7.839e-54`), 판정 열 기준 agent/obstacle 위반은 모두 0이다. `Cost.stalled`도 634,986번 후보 평가 중 69,144번(10.89%) True가 됐다.

**확인:** 1 Hz 준수율은 **91.30%**(4,156/4,552)로 100% 게이트에 미달했다. 절대 규칙에 따라 알고리즘을 고치지 않고 S5-1 클러스터링은 시작하지 않는다. 아래 지정 측정은 모두 수행했다.

## S2와 짝지은 비교

기준은 `results/s3/baseline_S2.csv` (horizon 4.0)다. `(uid, method, planner_seed)` 8,100행이 전부 조인됐다.

| 측정 | S2 h=4 | S5 h=10 | 확인 |
| --- | ---: | ---: | --- |
| wm 성공률 | 87.84% (4,269/4,860) | 93.66% (4,552/4,860) | +5.82%p |
| 성공 전이 | — | S5만 성공 329 / S2만 성공 46 | `p=7.839e-54` |
| 양쪽 성공 makespan | — | 차이(S5-S2) 중앙값 +0.000 s, p10 -0.300, p90 +0.400 | B승 1,038 / A승 1,111 / 동률 2,074, `p=0.1204` |

**추론:** 성공률 증가는 horizon이 길어지며 일부 deadlock을 피한 결과와 일치한다. 양쪽 성공 집합의 makespan은 유의하게 한쪽으로 움직이지 않았으므로, 이득을 기존 성공 건의 속도 향상으로 읽으면 안 된다.

| 항목 | 결과 |

안전 게이트는 `n_agent_violations == 0 AND n_obstacle_violations == 0`으로 판정했다.

## `Cost.stalled`와 실패 분류

| 항목 | 결과 |
| --- | ---: |
| 후보 평가 `n_evals` | 634,986 |
| `n_stalled_evals` | 69,144 |
| 후보 평가 기준 True 비율 | **10.89%** |
| True를 한 번 이상 낸 실행 행 | 3,663/4,860 (75.37%) |
| livelock / no_solution / timeout / 기타 | 0 / 0 / 0 / 0 |

wm_planner의 실패 308건은 전부 `unfinished:deadlock: no team progress`다. timeout은 없었다. **확인:** h=4에서 구조적으로 0이던 rollout 정체 판정이 h=10에서 실제로 작동한다.

## 시드 편차와 벽시계

| 측정 | 결과 |
| --- | --- |
| 시드 간 makespan 상대 편차 중앙값 / p90 | 1.17% / 7.69% |
| 재계획당 벽시계 중앙값 / p90 | 0.602 s / 0.978 s |
| 1 Hz 이내 | **91.30%** (4,156/4,552) |

재계획당 벽시계는 `runtime_s / team_time`으로 계산했다. `replan_s=1.0`이므로 재계획 횟수에 대한 근사이며 정확한 per-replan 타이머는 아니다.

## 게이트

| 게이트 | 결과 |
| --- | --- |
| 판정 열 기준 충돌 0 | 통과 |
| S2 대비 성공률 개선 | 통과 (+5.82%p) |
| `Cost.stalled` 실제 발동 | 통과 (10.89%) |
| 1 Hz 준수율 100% | **미달 (91.30%)** |

마지막 게이트 미달로 멈춘다. 따라서 `R_interact=3.0 m` 추가, 재계획 루프 배선, 궤적 불변 비교, k 분포 측정 및 슬롯 수 결정은 수행하지 않았다.

## 예상 밖 결과

P0-3의 약 +7.6%p 기대보다 작은 +5.82%p 개선이었다. 더 중요한 예상 밖 결과는 p90이 1초 안이면서도 개별 실행의 8.70%가 1초를 넘었다는 점이다. 중앙값이나 p90만으로 1 Hz 게이트를 통과했다고 말할 수 없었다.
