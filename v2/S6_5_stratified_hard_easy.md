# S6-5 — 층화 재분석: canonical 이 트리비얼하지 않은 자리에서도 모델이 지는가

표기: **확인** = 측정한 것 / **추론** = 측정에서 끌어낸 판단.
**재학습 없음.** S6-4 `geo` 와 S6-2 `ranking` 의 기존 체크포인트를 그대로 불러
예측만 다시 슬라이스했다. `learn/`, `config/`, 라벨 정의는 건드리지 않았다.

## 요약

- **게이트 1 통과, 게이트 2 형식상 통과(그러나 무효), 게이트 3 미달.**
- **게이트 1 에서 지시서의 층 정의 두 가지가 서로 다른 집합이라는 것이
  드러났다** (확인). "canonical 이 최소값 집합에 속한다"(val 59.8 %)와
  "전원 route 0 후보 중 하나가 최소값 집합에 속한다"(val 69.3 %)는 다르다.
  후자로 층을 잡으면 canonical regret 이 0 이 아니다 (val 평균 0.399 m,
  607 그룹 중 **83 그룹에서 0 이 아니다**). **S6-4 §8 은 이 둘을 같은 것으로
  놓았다** — §8 의 69.4 % 는 canonical 의 승률이 아니라 "전원 route 0"
  후보군 전체의 승률이었다.
- **hard 층에서 모델이 canonical 을 유의하게 이긴다** (val −0.452
  [−0.652, −0.258], test −0.301 [−0.499, −0.110]). **그러나 이것은 모델의
  능력이 아니라 층화가 만든 것이다** (확인). 층을 canonical 의 라벨로
  정의했으므로 hard 층에서 canonical 은 regret > 0 이 보장된다. **층 정의를
  모델 기준으로 뒤집으면 정확히 같은 크기의 우세가 canonical 쪽으로 간다**
  (canonical − geo: val −0.343 [−0.528, −0.162], test −0.482
  [−0.693, −0.288], 둘 다 유의). **게이트 2 는 통과했지만 답으로 쓸 수 없다.**
- **게이트 3 미달이 이번 단계의 진짜 답이다.** hard 층에서 모델은 **무작위와
  구별되지 않는다** (geo − random: val −0.008 [−0.228, +0.213], test
  −0.016 [−0.237, +0.200]). **모델은 canonical 에만 특히 약한 것이 아니라,
  canonical 이 못 푸는 자리에서는 아무것도 모른다** (추론).
- **규칙 C(하이브리드)는 정의가 공허했다** (확인). "전원 route 0 이 아닌
  후보가 하나라도 있는 그룹"은 **val·test 의 모든 그룹(100 %)** 이다.
  따라서 **규칙 C ≡ 규칙 B(항상 모델)** 이고, 소수점까지 같은 수가 나온다.
  canonical 단독보다 낫지 않다 (val −0.043 구별 안 됨, test +0.058 구별 안 됨).
- 규칙 D 는 test 에서 **유의하게 더 나쁘다** (+0.089 [+0.036, +0.150]).
  규칙 E 는 문턱이 val→test 로 옮겨가지 않는다.
- **층을 알면 canonical 을 유의하게 이긴다** (규칙 F: val 1.178 → 0.996,
  test 1.012 → 0.899, 둘 다 유의). **그런데 층은 라벨 없이 알아볼 수 없다** —
  실행 가능한 신호의 층 판별 AUC 가 0.45 ~ 0.52 로 전부 우연 수준이다 (확인).
- **결론: 라벨 재정의 말고 남은 길이 없다.** 코드는 고치지 않았다.

## 1. 층 정의 — 지시서의 두 표현은 다른 집합이다

지시서 §1 은 easy 를 "**canonical 이 정답 중 하나인 경우**"라고 쓰고, 같은
문장에서 그것을 "**전원 route 0 후보가 최소값 집합에 속함**"으로 바꿔 썼다.
S6-4 §8 이 둘을 같은 것으로 놓았기 때문이다. **둘은 같지 않다** (확인).

한 그룹에는 "전원 route 0" 후보가 **여러 개** 있다 — route 배정이 같아도
**양보 순서**가 다르면 다른 후보다.

| 그룹당 "전원 route 0" 후보 수 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| val 그룹 수 | 108 | 240 | 323 | 136 | 20 | 28 | 14 | 7 | — |
| test 그룹 수 | 106 | 224 | 332 | 157 | 22 | 44 | 12 | 6 | 3 |

canonical(`mode_idx=0`)은 그중 **하나**일 뿐이다 (route 전원 0 **이면서**
양보 순서가 `A>B>C>D`). 그래서 네 기준의 값이 다 다르다 (비퇴화 그룹 기준):

| 기준 | val | test |
|---|---:|---:|
| **canonical 이 최소값 집합에 속함** (= 이 보고서의 easy) | **59.8 %** | **62.6 %** |
| "전원 route 0" 후보 중 하나가 최소값 집합에 속함 (= S6-4 §8 의 69.4 %) | 69.3 % | 71.3 % |
| 그룹에 "전원 route 0" 후보가 존재함 | **100 %** | **100 %** |
| 그룹에 "전원 route 0 이 아닌" 후보가 존재함 | **100 %** | **100 %** |

**층으로는 첫 번째 기준을 썼다** — 지시서 §1 의 본문("canonical 이 정답 중
하나인 경우")과 게이트 1("easy 층에서 canonical regret 이 정확히 0")이 둘 다
그것을 가리키기 때문이다. 두 번째 기준은 게이트 1 을 통과할 수 없다 (§3).

### 대상 그룹 수

| | val | test |
|---|---:|---:|
| 전체 그룹 | 1,271 | 1,274 |
| 비퇴화 그룹 (S6-4 기준) | 878 | 913 |
| 그중 **canonical 후보가 없는** 그룹 | −2 | −7 |
| **이 보고서가 쓰는 그룹** | **876** | **906** |

canonical 이 없는 그룹은 canonical regret 이 정의되지 않아 뺐다 (확인:
val 2 건, test 7 건, 모두 크기 9~15 의 그룹). 그래서 아래 canonical·모델
평균이 S6-4 §6 의 값과 소수점 셋째 자리에서 다르다 (val 모델 1.132 → 1.135,
canonical 1.178 → 1.178; test 모델 1.084 → 1.069, canonical 1.012 → 1.012).

## 4. 게이트 2 를 무효로 만드는 검산 — 거울 층화

**hard 층은 "canonical 이 틀린 그룹"으로 정의됐다.** 그러므로 그 층에서
canonical 의 regret 은 정의상 0 보다 크고, 모델의 regret 은 그런 제약이 없다.
**층 정의 자체가 canonical 에게 불리하다.**

같은 방식으로 층을 **모델 기준**으로 뒤집어 봤다 (`mirror_check`,
"geo 의 regret > 0 인 그룹"):

| 거울 층 (모델이 틀린 그룹) | val (41.2 %, n=361) | test (39.8 %, n=361) |
|---|---:|---:|
| geo | 2.754 | 2.684 |
| canonical | **2.411** | **2.201** |
| 무작위 | 2.373 | 2.398 |
| **canonical − geo** | **−0.343 [−0.528, −0.162] 유의** | **−0.482 [−0.693, −0.288] 유의** |

**확인: 크기도 부호도 대칭이다.** 층을 누구의 라벨로 정의하느냐에 따라
"유의한 승자"가 그대로 뒤집힌다. **게이트 2 의 통과는 모델의 성질이 아니라
층화 절차의 성질이다** (추론). 이 검산이 없었으면 "hard 층에서는 모델이
canonical 을 이긴다"를 결론으로 적을 뻔했다.

**층화에 오염되지 않은 비교는 게이트 3 하나뿐이고, 그것은 미달이다.**
(무작위 기준선은 층 정의에 쓰이지 않았으므로 hard 층 안에서 모델과 공정하게
비교된다.)

### S6-4 의 무승부는 어디서 나왔나 — 기여도 분해

| val | 비중 | 모델 regret | 기여 | canonical regret | 기여 |
|---|---:|---:|---:|---:|---:|
| easy | 59.8 % | 0.232 | **+0.139** | 0.000 | 0.000 |
| hard | 40.2 % | 2.479 | +0.996 | 2.931 | +1.178 |
| **합계** | | | **1.135** | | **1.178** |

| test | 비중 | 모델 regret | 기여 | canonical regret | 기여 |
|---|---:|---:|---:|---:|---:|
| easy | 62.6 % | 0.272 | **+0.170** | 0.000 | 0.000 |
| hard | 37.4 % | 2.402 | +0.899 | 2.703 | +1.012 |
| **합계** | | | **1.069** | | **1.012** |

**확인: 모델과 canonical 의 총합 차이는 두 항의 상쇄다.** 모델은 hard 층에서
0.182 m(val) / 0.113 m(test) 를 벌고, easy 층에서 0.139 m / 0.170 m 를 잃는다.
val 에서는 벌이가 근소하게 커서 −0.043, test 에서는 손실이 커서 +0.058 —
**S6-2·S6-4 가 네 번 반복해서 본 "구별 안 됨"의 정체가 이 상쇄다** (추론).

그리고 hard 층의 벌이는 §4 앞부분에 따라 **모델의 실력이 아니다** — 그 층에서
모델은 무작위와 같다. **즉 모델이 canonical 대비 얻는 것은 "canonical 이
확실히 틀리는 자리에서 무작위로 찍는 값어치"뿐이고, 그 대가로 canonical 이
맞히는 자리를 망친다** (추론).

## 5. 하이브리드 규칙 — 재학습 없이 조합만

전체(easy+hard 통합) 평균 regret. 비교는 전부 canonical(규칙 A) 대비
짝지은 부트스트랩이다.

| 규칙 | 모델 사용 비율 | val 평균 | val vs A | test 평균 | test vs A |
|---|---:|---:|:---:|---:|:---:|
| **A** 항상 canonical | 0 % | **1.178** | — | **1.012** | — |
| **B** 항상 모델 | 100 % | 1.135 | −0.043 [−0.138, +0.056] 구별 안 됨 | 1.069 | +0.058 [−0.038, +0.154] 구별 안 됨 |
| **C** 하이브리드(전원 route 0 아닌 후보 존재 시 모델) | **100 %** | **1.135** | −0.043 [−0.141, +0.056] 구별 안 됨 | **1.069** | +0.058 [−0.037, +0.155] 구별 안 됨 |
| **D** canonical 의 P(정체) 상위 25 % 만 모델 | 25.0 / 25.7 % | 1.161 | −0.017 [−0.070, +0.036] 구별 안 됨 | 1.100 | **+0.089 [+0.036, +0.150] 유의하게 나쁨** |
| **E** 모델이 본 canonical 열세폭 > δ 일 때만 모델 | 57.3 / 58.8 % | 1.135 | −0.043 [−0.143, +0.054] 구별 안 됨 | 1.069 | +0.058 [−0.040, +0.156] 구별 안 됨 |
| **F** *층을 아는 오라클* (hard 면 모델) | 40.2 / 37.4 % | **0.996** | **−0.182 [−0.265, −0.102] 유의** | **0.899** | **−0.113 [−0.185, −0.040] 유의** |

### 규칙 C 는 조건이 공허하다 (확인)

지시서가 구분하라고 지목한 두 조건을 따로 셌더니:

- "그룹에 **전원 route 0 후보가 존재**하는가" → **모든 그룹에서 참** (100 %)
- "그룹에 **전원 route 0 이 아닌 후보가 존재**하는가" → **모든 그룹에서 참** (100 %)
- "그 후보가 **최소값인가**" → 69.3 % (val) — 이것만 그룹을 실제로 가른다

그룹 크기는 12~16 이고 그중 "전원 route 0" 후보가 1~9 개다. **어느 쪽도 0 이나
전부가 되는 그룹이 없다.** 그래서 **규칙 C 의 조건은 항상 참이고, 규칙 C 는
규칙 B 와 완전히 같은 규칙이다** — 표의 두 줄이 소수점까지 같은 이유다.
(부트스트랩 구간만 난수 상태 차이로 셋째 자리에서 다르다.)

**지시서 "미달 시" 항목의 답: 규칙 C 는 canonical 단독보다 낫지 않다.**
val 에서 −0.043 m 로 방향은 맞지만 구간이 0 을 넘고, test 에서는 부호가
뒤집힌다. **라벨 재정의 없이 쓸 수 있는 실용적 결론은 나오지 않았다.**

### 규칙 D · E 도 안 된다

D 의 문턱은 **val 에서 정해 test 에 그대로 적용**했다 (P(정체) 상위 25 %
= 0.0725). 분위수를 훑어도 val 에서 canonical 을 유의하게 이기는 지점이 없다:

| 모델로 대체하는 비율 | 10 % | 25 % | 50 % | 75 % |
|---|---:|---:|---:|---:|
| val 평균 regret | 1.180 | 1.161 | 1.155 | 1.150 |
| test 평균 regret | 1.044 | 1.094 | 1.082 | 1.058 |

**val 은 많이 대체할수록 좋아지고(=규칙 B 로 수렴) test 는 순서가 뒤죽박죽이다**
— P(정체)가 층을 가리키지 않는다는 뜻이다 (추론, §6 에서 AUC 로 확인).

E 는 "모델이 canonical 을 최선보다 δ 이상 나쁘다고 볼 때만 교체"다. 라벨을
쓰지 않으므로 실제로 굴릴 수 있다. **val 에서 최적 δ 는 0.0** (= 사실상 규칙 B,
1.135)이고 δ 를 올릴수록 나빠진다. **test 에서 최적 δ 는 0.266** (0.9996,
canonical 1.012 보다 근소하게 낫다). **문턱이 옮겨가지 않는다** — val 에서
고른 δ=0.0 을 test 에 적용하면 1.069 로 canonical 보다 나쁘다.

---

## 6. 규칙 F 가 실행 가능한가 — 아니다

**F 는 유일하게 canonical 을 유의하게 이겼다** (val −0.182, test −0.113).
그 이득의 크기는 §4 의 hard 층 기여 차이와 정확히 같다 (1.178 − 0.996 = 0.182).
**F 는 "easy 층에서 모델이 입히는 손해를 없앤 것"일 뿐이고, 층을 알아야만
계산된다** — 라벨이 있어야 한다.

그래서 **층을 라벨 없이 알아볼 수 있는지**를 쟀다 (hard 를 양성으로 한 AUC,
`layer_predictability.json`):

| 층 판별 신호 | val | test | 실행 가능? |
|---|---:|---:|:---:|
| 모델이 본 canonical 열세폭 (규칙 E 의 근거) | **0.452** | **0.517** | 가능 |
| canonical 의 P(정체) (규칙 D 의 근거) | **0.492** | **0.503** | 가능 |
| 그룹 크기 | 0.503 | 0.501 | 가능 |
| *그룹의 loss 폭 (max−min)* | *0.679* | *0.615* | **불가 (라벨)** |

**확인: 실행 가능한 신호 셋은 전부 우연 수준(0.45 ~ 0.52)이다.** val 의
열세폭 AUC 0.452 는 **0.5 보다 낮다** — 모델은 자기가 canonical 을 이길
그룹을 고르기는커녕 반대 방향으로 살짝 기울어 있다 (확인). **규칙 D 가
test 에서 유의하게 나빠진 것이 이것의 직접적인 결과다** (추론).

라벨을 봐야 계산되는 loss 폭만 0.62 ~ 0.68 로 정보가 있다. **hard/easy 를
가르는 것은 "그룹 안에서 선택이 실제로 중요한가"인데, 그 양은 라벨 없이는
지금 특성으로 알 수 없다** (추론).

## 7. 규칙 C 가 canonical 과 다르게 고른 사례

규칙 C 는 모든 그룹에서 모델을 쓰므로, "다른 선택"은 모델의 1등이 canonical 과
다른 그룹 전부다 — **val 502 건 / test 533 건** (비퇴화 그룹의 57 % / 59 %).
`hybrid_examples.json` 에 실제 loss 차이 `delta = loss(모델) − loss(canonical)`
가 큰 상위 20 건을 split 별로 담았다.

| | 모델이 더 나쁨 | 모델이 더 좋음 | delta 범위 (m) |
|---|---:|---:|---|
| val 상위 20 | 11 | 9 | −8.16 … +10.15 |
| test 상위 20 | 11 | 9 | −7.56 … +11.52 |

**확인: 큰 차이가 나는 자리에서 방향이 반반이다.** 최악의 val 사례
(`n4_chain_e1d272d0` replan 3)는 canonical 이 그룹 최소값 0.000 을 맞히는데
모델이 10.15 m 짜리를 골랐다. 반대로 `n4_none_b3f077f0` replan 0 은
canonical 이 10.20 m, 모델이 2.04 m(그룹 최소 1.79 m)다.

**추론: 모델의 선택은 canonical 과 "다르게 크게 틀리거나 다르게 크게 맞는"
관계이지, canonical 을 보정하는 관계가 아니다.** §6 의 AUC 가 우연 수준인
것과 같은 사실의 다른 표현이다.

## 8. 결론

| 질문 | 답 |
|---|---|
| (1) 모델이 "어려운" 상황에서도 canonical 에 지는가 | **비긴다 — 하지만 그 비김은 무의미하다.** hard 층에서 모델은 canonical 을 유의하게 이기지만(게이트 2), 층 정의가 canonical 에게 불리해서 생긴 것이고(§4 거울 검산), 같은 층에서 **무작위와 구별되지 않는다**(게이트 3 미달). |
| (2) 재학습 없이 모델+canonical 하이브리드가 canonical 단독보다 나은가 | **아니다.** 규칙 C 는 조건이 공허해 규칙 B 와 같고, canonical 대비 구별되지 않는다(val) / 나쁜 쪽(test). 규칙 D 는 test 에서 유의하게 나쁘다. 규칙 E 는 문턱이 옮겨가지 않는다. |
| 층을 알면? | **canonical 을 유의하게 이긴다** (규칙 F, val −0.182 / test −0.113). **그런데 층은 라벨 없이 알아볼 수 없다** (AUC 0.45 ~ 0.52). |

**따라서 지시서의 "미달 시" 조항대로 명시한다 — 다음 단계는 라벨 재정의뿐이다.**
S5-3E 의 `loss_max` 정의를 **route 선택과 독립적으로** 만드는 것.
근거는 세 겹이다:

1. 라벨이 route 0 을 공통 자로 쓰기 때문에 "전원 route 0" 후보가 최소값의
   69 ~ 71 % 를 차지한다 (S6-4 §8, 이번에 그중 canonical 몫이 59.8 / 62.6 %
   임을 분리해 확인).
2. **모델이 canonical 을 이길 수 있는 유일한 자리(hard 층)에서 모델은 무작위와
   같다** — 이 층에서 배울 신호를 지금 라벨은 제공하지 않는다 (추론).
3. **그 층을 실행 가능한 신호로 알아볼 수도 없다** — 하이브리드로 우회하는
   길이 닫혔다 (§6).

**코드는 고치지 않았다.**

## 9. 예상과 달랐던 것

1. **지시서가 준 easy 정의 두 개가 서로 다른 집합이었다.** 게이트 1 이
   정확히 그 차이를 잡아냈다 — "정의 확인용"이라고 적힌 게이트가 실제로
   S6-4 §8 의 해석 하나를 정정했다.
2. **규칙 C 의 조건이 100 % 참이었다.** 지시서가 "다른지 확인할 것"이라고
   단서를 단 그 지점에서, 두 조건 중 하나가 아예 그룹을 가르지 못했다.
   그룹마다 전원-route 0 후보가 1~9 개씩 늘 섞여 있다.
3. **거울 층화가 대칭이었다.** 게이트 2 를 통과했을 때 잠깐 "드디어 이겼다"로
   보였는데, 층 정의를 뒤집자 같은 크기의 유의한 우세가 canonical 로 갔다.
   **라벨로 정의한 층에서 그 라벨의 주인공과 비교하면 안 된다.**
4. **hard 층에서 canonical(2.93)이 무작위(2.49)보다 나쁘다.** 조건부 선택의
   결과이지만, "canonical 은 틀릴 때 크게 틀린다"는 것도 사실이다.
5. **모델의 자기 확신이 층과 역상관이었다** (val AUC 0.452 < 0.5). 모델이
   "canonical 이 나쁘다"고 강하게 볼수록 오히려 easy 층일 확률이 높다.
6. **easy 층에서는 geo 가 ranking 보다 뚜렷이 낫다** (test 0.272 vs 0.415).
   S6-4 의 tau-b 개선이 실제로 나타나는 자리가 여기라는 뜻인데, 하필
   canonical 이 이미 0 인 층이라 총합에 보탬이 안 된다.

## 남은 불확실성

- **층을 canonical 기준으로 잡을 수밖에 없었다.** §4 가 보였듯 라벨로 정의한
  층 안에서의 비교는 정의의 주인공에게 불리하다. 게이트 3(무작위 대비)만이
  오염되지 않은 비교이고, 그래서 이번 단계가 실제로 답한 것은 게이트 3 뿐이다.
- **규칙 E 의 문턱을 test 에서 훑은 값(0.266, 0.9996)이 canonical 보다 근소히
  낫다.** test 에서 고른 값이므로 성능 주장으로 쓸 수 없다. val 에서 재현되지
  않으니 잡음일 가능성이 크지만(추론), 별도 split 없이는 가릴 수 없다.
- **canonical 이 없는 그룹 9 건(val 2 / test 7)을 뺐다.** 비율이 1 % 미만이라
  결론에 영향은 없지만, S6-4 §6 의 표와 그룹 수가 다른 이유다.
- **`P(정체)` 말고 다른 확신도 신호를 다 훑지는 않았다.** 규칙 D 는 지시서가
  예시로 든 정의를 그대로 썼고, 규칙 E 로 하나를 더 봤을 뿐이다. 다만 §6 에서
  두 신호 다 AUC 가 우연 수준이라 다른 조합에서 갑자기 층이 보일 이유는
  약하다 (추론).
- **양보 순서 자유도를 측정만 했다.** §3 의 83 그룹(전원 route 0 이 최소지만
  canonical 은 아님)은 "route 가 아니라 양보 순서가 결정적인" 자리다. 이 부분
  집합만 따로 학습 대상으로 삼는 것은 이번 축 밖이다.
