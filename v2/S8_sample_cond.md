  어느 것도 canonical 을 유의하게 이기지 못한다. **부호가 split 마다 뒤집힌다:**

  | **S2** 둘 다 필터 | **+0.141 [−0.070, +0.355]** | **−0.089 [−0.255, +0.075]** |
  | **S3′** 학습만 필터 | +0.141 [−0.064, +0.353] | −0.089 [−0.257, +0.072] |

  전부 구간이 0 을 넘는다. **다섯 번째 시도에서도 답은 "아니오"다.**
- **표본을 거르면 오히려 나빠지는 쪽이 우세하다** (확인). 전체·비퇴화 범위에서
  S2 는 test 에서 **유의하게 나쁘다** (+0.129 [+0.010, +0.248]).
- **그런데 필터는 분류를 실제로 개선한다** (확인, 같은 행 위에서 비교).
  활성 그룹의 `stalled` AUC 가 **0.681 → 0.739**(val) / **0.703 → 0.749**(test),
  3-클래스 정확도 0.787 → 0.870 / 0.725 → 0.826. **분류가 좋아져도 top-1 은
  움직이지 않는다** — S6-4 §7 이 표현 축에서 본 괴리가 표본 축에서 되풀이된다.
- **C-3 거울 검산이 지시서의 우려를 정확히 확인했다.** 활성 필터 자체는
  대칭이다 (canonical 이 틀린 그룹 비율 66.0 %, 모델이 틀린 그룹 비율 67.7 %,
  val S1) — **S6-5 §4 의 함정이 아니다.** 그러나 같은 활성 그룹 안에서
  **선택자의 라벨로 층을 나누면 즉시 유의가 나타나고 승자가 뒤바뀐다**
  (test S1: "모델이 틀린 층"에서 canonical 이 −0.404 유의; test S2:
  "canonical 이 틀린 층"에서 모델이 −0.303 유의). **주 비교가 그 층화를 쓰지
  않는다는 것이 S8 판정의 전제다.**
- **활성 그룹에서는 모델이 무작위보다 유의하게 낫다** (S1 −0.571 / −0.595,
  전부 유의). **S6-5 hard 층에서 무작위와 구별되지 않던 것과 다르다** (확인).
  다만 canonical 도 무작위보다 유의하게 낫고 (−0.539 / −0.745), 둘 사이가
  구별되지 않는다.
- **S3(지시서 정의 그대로)는 조기 종료와 충돌해 1 에폭 모델이 뽑혔다** (확인).
  train 에 "상호작용 없음" 클래스가 0 % 인데 전체 val 의 58.6 % 가 그 클래스라
  `val_cls` 가 학습할수록 **단조 증가**한다 (3.45 → 5.92). 그 체크포인트는
  후보의 **73 %** 에서 canonical 을 고른다 — **성적이 모델의 것이 아니다.**
  S3 의 의도(학습만 필터, 평가는 전체)의 실질은 **S3′**(S2 체크포인트를 전체
  표본에서 평가)로 따로 쟀다.
- 게이트 6종 전부 수행. **순열 불변성은 세 조건 다 통과** (최대 1.43e-06).
- **원인 후보 (a)~(e) 가 전부 기각되거나 불충분으로 판정됐다.** 지시서대로
  **문제 설정 자체의 재검토**가 남았다 — §7 에 측정으로 좁힌 선택지를 적었다.
  **코드는 고치지 않았다.**

## A — 표본 조건 세 가지

### 정의

**활성 그룹(active)** = 그룹의 `loss_max` **최소값 > 0** 인 그룹.
S7 이 확정한 것: 최소값이 0 인 그룹에서는 후보 다수가 0 으로 동점이고
canonical 이 자동으로 정답 집합에 들어가므로 어떤 모델도 그보다 잘할 수 없다.

**두 가지 "퇴화"를 구분한다** (혼동을 막기 위해 둘 다 보고한다):

| 이름 | 정의 | val 그룹 | test 그룹 |
|---|---|---:|---:|
| **활성** | 그룹 최소값 > 0 | **235 / 1,271 (18.5 %)** | **258 / 1,274 (20.3 %)** |
| 비퇴화 | 그룹 max ≠ min (S6-5·`evaluate.py`) | 878 (69.1 %) | 913 (71.7 %) |

전체 135,597 행 8,482 그룹 중 활성 그룹은 **2,258 (26.6 %)**, 비퇴화 그룹은
6,381 (75.2 %) 이다.

### 구현 — 라벨도 텐서도 건드리지 않았다

`scripts/make_s8_caches.py` 가 `s6_4.npz` 를 읽어 **`split` 열만** 바꾼다.
제외할 행은 `drop` 으로 표시하면 `learn/common.split_of` 가 자연히 걸러낸다.
텐서·라벨·`gid`·`uid` 는 한 바이트도 바뀌지 않는다.

## B — 학습

**모델 구조·손실·용량·시드·배치·lr·patience 를 S6-4 `geo` 와 동일하게 고정했다**
(`--variant A3 --lam-rank 1.0 --seed 20260901 --batch 512 --lr 3e-4

### ⚠ S3 는 조기 종료 기준과 충돌한다 (확인)

S3 는 train 에 **"상호작용 없음"(cls3=0) 행이 0 %** 인데 평가하는 전체 val 의
**58.6 %** 가 그 클래스다. 그래서 분류 교차엔트로피가 **학습할수록 커진다**:

| S3 의 val | ep 0 | ep 1 | ep 2 | ep 5 | ep 8 | ep 15 | ep 25 |
|---|---:|---:|---:|---:|---:|---:|---:|
| `val_cls` | **3.452** | 3.500 | 3.679 | 4.159 | 4.471 | 4.965 | **5.924** |
| `val_rank` | 2.7362 | 2.7318 | **2.7314** | 2.7375 | 2.7406 | 2.7564 | 2.8110 |
| `val_total` | **7.242** | 7.307 | 7.469 | 8.002 | 8.210 | 8.904 | 10.019 |

**`val_rank` 는 ep 2 까지 내려가는데** 조기 종료 기준
(`CE + MSE + L_rank`)에서 CE 가 크기를 지배해 **첫 에폭 모델이 뽑혔다.**
S6-4 §4 가 지적한 "조기 종료가 순위 항을 사실상 무시한다"가 여기서 극단으로
나타난다 (추론).

**그 체크포인트는 후보의 73 % 에서 canonical 을 고른다** (val 0.731 /
test 0.709; 다른 조건은 0.28~0.42). **S3 의 regret 이 canonical 과 거의 같은
것은 모델이 잘해서가 아니라 canonical 을 흉내내기 때문이다** (확인).
아래 표에서 S3 를 **모델의 성적으로 읽으면 안 된다.**

**그래서 S3′ 를 따로 잰다** — S2 체크포인트(같은 train, 활성 val 로 선택)를
**전체 표본에서 평가**한 것. 이것이 "학습만 필터, 평가는 전체"의 실질이다.
조기 종료 기준을 바꾸는 것은 이번 축 밖이라 하지 않았다.

## C — 평가

세 모델의 점수를 **전체 캐시의 val/test 전 행에서** 계산한 뒤 그룹 부분집합만
바꿔 비교한다 (`scripts/eval_s8.py`). 순위 점수의 정체 항 L̄₂ 는 **모델마다
학습에 쓴 train 에서** 가져온다 — 평가 캐시에서 다시 계산하면 학습 때 쓴 값과
달라져 점수가 틀어진다.

**확인 셋:**

1. **활성 그룹에서 세 조건 다 canonical 과 구별되지 않고, 부호가 split 마다
   뒤집힌다.** S1 은 val 에서 −0.032 / test 에서 +0.150, S2 는 val 에서
   +0.141 / test 에서 −0.089. **표본이 235·255 그룹이라 구간이 넓다** —
   구간 폭이 ±0.2~0.4 m 로 S6-5(±0.1 m)의 2~4 배다.
2. **표본을 거르면 오히려 나빠지는 쪽이 우세하다.** S2 는 전체·비퇴화 범위의
   test 에서 canonical 보다 **유의하게 나쁘다.** 학습 행이 94,949 → 28,225 로
   줄어든 대가다 (추론 — S6-3 D2 는 18배 축소로도 val 이득이 0 이었으므로
   용량 문제는 아니고, 필터가 **분포를 바꾼** 결과로 본다).
3. **활성 그룹에서는 모델이 무작위보다 유의하게 낫다.** S6-5 의 hard 층에서
   모델이 무작위와 구별되지 않았던 것과 **다르다.** 즉 활성 그룹은
   S6-5 의 hard 층과 같은 자리가 아니고, 여기서는 모델이 실제로 무언가를
   안다 — **그런데 canonical 도 같은 만큼 안다.**

### C-3. 거울 검산 (필수)

**활성 필터는 그룹 전체의 라벨로 정의되고 어느 선택자의 성적도 쓰지 않는다.**
그래도 지시서대로 확인했다.

| 활성 그룹 안에서 | val (n=235) | test (n=255) |
|---|---:|---:|
| canonical 이 틀린 그룹 비율 | 66.0 % | 62.4 % |
| 모델(S1)이 틀린 그룹 비율 | 67.7 % | 65.9 % |
| 모델(S2)이 틀린 그룹 비율 | 72.3 % | 63.1 % |

**두 비율이 거의 같다 — 필터는 어느 쪽에도 유리하지 않다** (확인).

그런데 **같은 활성 그룹 안에서 선택자의 라벨로 층을 나누면 즉시 대칭적 유의가
나타난다** (S6-5 §4 의 재현):

| 층 | 비교 | val | test |
|---|---|:---:|:---:|
| (층화 없음) | S1 − canonical | −0.032 [−0.190, +0.117] | +0.150 [−0.078, +0.387] |
| canonical 이 틀린 층 | S1 − canonical | −0.102 [−0.335, +0.121] | −0.085 [−0.373, +0.207] |

## 7. 남은 것 — 문제 설정 재검토 (실행하지 않았다)

지시서대로 판단은 함께 하기로 되어 있으므로, **측정으로 좁힌 선택지만** 적는다.

1. **"1 등을 맞히는 것"이 옳은 목표인지.** 다섯 축에서 일관되게 나온 패턴은
   **모델이 그룹 내 순서는 canonical 의 2 배로 잘 알면서 top-1 만 못 맞힌다**는
   것이다 (활성 그룹 tau-b 0.208 vs 0.104, top-1 0.290 vs 0.308). 활성 그룹의
   최소 동점 후보가 평균 6~7 개라 top-1 은 그 동점 집합을 맞히는 문제인데,
   순위 신호는 그 집합 **밖**의 순서에서 나온다 (추론).
2. **조기 종료 기준이 순위 항을 무시한다.** S6-4 §4 에서 "val 순위 손실은
   ep 29 까지 내려가는데 ep 2 에서 멈췄다", S8 S3 에서는 그 충돌이 극단으로
   나타나 1 에폭 모델이 뽑혔다. **기준을 `L_rank` 로 바꾸면 어떻게 되는지
   아직 아무도 재지 않았다.** 이번 축 밖이라 하지 않았다.
3. **활성 그룹이 235·255 개뿐이다.** 부트스트랩 구간이 ±0.2~0.4 m 로 넓어
   0.1 m 수준의 차이는 원리적으로 검출할 수 없다. 활성 그룹을 더 얻으려면
   라벨 수집 자체를 활성 조건 쪽으로 층화해야 한다 (S5-3E 가 남긴
   "클러스터 판정을 예측 궤적 최소거리로" 선택지).
4. **canonical 이 강한 기준선이라는 사실 자체.** 활성 그룹에서도 canonical 은
   무작위보다 −0.539 / −0.745 유의하게 낫다. 최단 경로 + 항등 양보 순서는
   **학습 없이도 좋은 정책**이고, 그것을 넘으려면 모델이 배워야 할 것은
   "canonical 이 틀리는 33~38 % 를 찾아내는 것"인데 S6-5 §6 에서 그 층은
   실행 가능한 신호로 예측 불가(AUC 0.45~0.52)로 판정됐다.

## 예상과 달랐던 것

1. **S3 가 조기 종료와 충돌해 1 에폭 모델을 뽑았다.** train 에 없는 클래스가
   val 의 58.6 % 를 차지하면 CE 가 학습할수록 커진다는 것을 설계할 때
   생각하지 못했다. "학습만 필터"는 손실 구성까지 함께 손대야 성립한다.
2. **그 1 에폭 모델이 canonical 을 73 % 고른다.** 그래서 regret 이 canonical
   과 거의 같게 나왔고, 표만 보면 "S3 가 제일 낫다"로 읽힌다. 선택률을 재보지
   않았으면 그렇게 보고할 뻔했다.
3. **필터가 분류를 크게 개선했다** (활성 AUC 0.681 → 0.739). 표본을 1/3 로
   줄였는데 분류가 좋아졌다 — 클래스 0 이 빠지면서 남은 두 클래스의 경계가
   선명해진 것으로 본다 (추론). 그런데 **top-1 은 전혀 안 움직였다.**
4. **활성 그룹에서 모델이 무작위보다 유의하게 낫다.** S6-5 hard 층의 "무작위와
   구별 안 됨"을 그대로 이어받을 줄 알았는데 아니었다. 두 층이 다른 자리다.
5. **필터가 오히려 손해였다.** S2 가 전체·비퇴화 test 에서 canonical 보다
   **유의하게 나쁘다.** "동점 그룹을 빼면 배울 것이 선명해진다"는 기대와
   반대 방향이다.
6. **부호가 split 마다 뒤집힌다.** S1 은 val −0.032 / test +0.150, S2 는
   val +0.141 / test −0.089. 활성 그룹이 235·255 개라 구간이 S6-5 의 2~4 배로
   넓다 — 이 규모에서는 어느 쪽도 주장할 수 없다.
7. **거울 검산이 활성 그룹 안에서도 대칭을 재현했다.** 필터 자체는 대칭인데,
   그 안에서 선택자 기준으로 한 번 더 나누면 즉시 유의가 튀어나온다. S6-5 에서
   배운 함정이 축을 바꿔도 그대로 있다는 것을 확인했다.

  "무승부"는 **차이가 없다는 증명이 아니라 이 표본으로는 못 가린다는 뜻**이다.
- **S3 를 지시서 정의대로만 평가했다.** 조기 종료 기준을 순위 손실로 바꾸면
  S3 가 달라질 수 있으나 그것은 다른 축이라 하지 않았다. S3′ 가 그 대용이지만
  **모델 선택을 활성 val 로 한 것이라 완전한 대용은 아니다.**
- **필터 기준을 `min > 0` 하나만 썼다.** "동점 집합 크기 ≤ T" 같은 다른 기준은
  재지 않았다. S7 이 동점 크기를 문제로 지목했으므로 그쪽이 더 직접적인
  필터일 수 있다 (추론).
- **S2 가 test 활성 그룹에서 −0.089, k=4 에서 −0.427 로 방향은 좋다.**
  val 에서 재현되지 않아 잡음으로 보지만, k=4 활성 그룹이 28 개뿐이라
  가릴 수 없다.
- **분류 개선(AUC +0.057)이 downstream 에 쓸모가 있는지 재지 않았다.**
  top-1 regret 에는 나타나지 않았지만, 통합 시 정체 예측 자체가 쓰이는
  자리가 따로 있다면 (계획서 §6) 그 값은 별개로 볼 수 있다.
